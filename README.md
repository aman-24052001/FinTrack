# FinTrack - Personal Finance Manager

![FinTrack](https://img.shields.io/badge/FinTrack-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Dependencies](https://img.shields.io/badge/dependencies-up%20to%20date-brightgreen)

FinTrack is a modern, responsive web application for personal finance management. Built with vanilla JavaScript and popular frontend libraries, it offers an intuitive interface for tracking income, expenses, and analyzing financial patterns.

## 🌟 Features

- **User Authentication**
  - Secure registration and login system
  - Local storage-based data persistence
  - Password validation with minimum security requirements

- **Transaction Management**
  - Add, edit, and delete financial transactions
  - Categorize transactions as income or expenses
  - Date-based transaction organization
  - Detailed transaction history

- **Financial Analytics**
  - Real-time balance calculation
  - Income vs Expenses trend analysis
  - Monthly financial patterns visualization
  - Expense distribution overview

- **Interactive Dashboard**
  - Clean, modern user interface
  - Responsive design for all devices
  - Real-time updates
  - Intuitive data visualization

## 🛠️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/fintrack.git
   cd fintrack
   ```

2. **Setup Options**

   **Option 1: Direct Usage**
   - Open `index.html` in your web browser
   - No build process required

   **Option 2: Using a Local Server**
   - Install a simple HTTP server:
     ```bash
     npm install -g http-server
     ```
   - Run the server:
     ```bash
     http-server
     ```
   - Open `http://localhost:8080` in your browser

## 📱 How to Use

1. **Getting Started**
   - Register a new account using your email and password
   - Login with your credentials
   - You'll be directed to the main dashboard

2. **Managing Transactions**
   - Click "Add Transaction" to record new income or expenses
   - Fill in the transaction details:
     - Description
     - Amount
     - Type (Income/Expense)
     - Date
   - View your transaction history in the dashboard
   - Edit or delete transactions using the action buttons

3. **Analyzing Finances**
   - View total income, expenses, and current balance
   - Check the line chart for monthly trends
   - Use the pie chart to understand expense distribution
   - Track your financial progress over time

## 🔒 Security Features

- Password requirements enforced (minimum 8 characters, letters, and numbers)
- Client-side form validation
- Secure session management
- Protected dashboard access

## 💡 Best Practices

- Follow these guidelines when using FinTrack:
  - Regularly review your transactions
  - Keep descriptions clear and specific
  - Categorize transactions correctly
  - Back up your data periodically
  - Log out after each session
